DFLegacy —— DNF 60 版单机端
============================

> 本文是随游戏目录一起分发的说明。仓库内的 `d3d8/d3d8.dll`
> 即下文中提到的适配文件；若你拿到的是打包好的目录，
> 它位于 `_Winlator\d3d8.dll`。

【直接运行】
双击 DNF.exe 即可。
首次启动会自动拉起服务端（无窗口），约 1~2 秒后进入登录界面。
关掉游戏，服务端会自动退出，不留残留进程。

不需要安装 .NET 运行时、不需要注册表、不需要安装程序。
整个目录可以随便移动位置，也可以直接拷到别的电脑。


【配置文件】
Config.ini
  [Resolution]  窗口分辨率，建议保持 4:3（如 1920x1440、1600x1200）
  [Launcher]    账号密码、入口地址、是否自动起服务端、退出是否联动
server.json
  服务端端口、掉落倍率、经验倍率、数据包跟踪等
data\state.json
  存档文件，所有角色数据都在这里


【Winlator / Wine / ARM 设备】
把 d3d8.dll 复制到本目录根下（和 DNF.exe 同级）。
在仓库里它是 d3d8/d3d8.dll；在打包好的目录里是 _Winlator/d3d8.dll。

作用：DNF 只认 D3D8，而 DXVK 只支持 D3D9 及以上。
这个 d3d8.dll 是 d3d8to9 包装层，把 D3D8 调用翻译成 D3D9，
再由 DXVK 转成 Vulkan，才能在 Android 上渲染。

注意：Windows 本机不要放这个文件，否则渲染路径会变（虽然通常没问题）。


【后台管理】
浏览器打开：http://127.0.0.1:8081/admin/index.html
可以发点券、发邮件、改等级/疲劳、查角色、看服务端状态。

游戏内充值页走的是 http://127.0.0.1:8081/client/client_pay.htm，
所以 wwwroot 目录不能删。


【存档备份】
复制一份 data\state.json 即可。
不要在服务端运行时手动编辑这个文件。


【回滚】
ijl15.original.dll 是原版 ijl15，改名回 ijl15.dll 即可恢复
"无启动引导"的状态（但那样就必须用启动器或带参数启动 DNF.exe）。


【文件说明】
DNF.exe              客户端主程序
Script.pvf           游戏脚本数据（65 MB）
ImagePacks2\         美术资源（425 个 NPK，488 MB）
SoundPacks\ Music\   音效与背景音乐
ijl15.dll            原版增强 + 启动引导（本项目核心改动）
DFLegacy.Server.exe  服务端（Native AOT，x86，无需运行时）
wwwroot\             充值页 + 后台管理页
data\                存档
